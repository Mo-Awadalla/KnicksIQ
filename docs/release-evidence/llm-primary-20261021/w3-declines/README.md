## Offline fix and reproduction

`reproduce_declines.py` exercises the real local release `2025-26.20260928.1` (101
games) through `AnalystTools`, `prefetch_calls`, `fallback_claims` and
`render_fallback`. It writes `repro-base.json` (before: 11 of 73 checks pass) and
`repro-head.json` (after: 73 of 73). Checks cover routing, exact claim values, fallback
text, unchanged single-population routes, the metric gate, and the prompt contract.

- `get_team_splits` returns 18-9 after the All-Star break, 7-3 in the first 10,
  119.00/114.02 points per game home/road, 3-1 vs BOS and 5-0 vs TOR, 7-3 and 6-4
  first/last 10.
- `get_game_flow` returns the 20-0 biggest run, the 15-0 PHX opponent run, the
  21-point deficit erased, the 14-point lead lost, and the 19-point lead lost for
  the worst-collapse question.
- `get_period_scoring` returns the Q4 report for all four CHI games and the halftime
  report for all four CHA games instead of an entity ambiguity.
- A reviewer rejection after any of those tools now renders the computed claims
  instead of "I can't answer that".

## Unsupported questions answered instead of declined: 5 of 20

The five honest failures are not five answers that should have been declines:

- `unsupported-009` and `unsupported-010`, both trials: the app asks which game

  A 20/20 declined target contradicts the labels.

  line without a claim. The prompt now forbids unbacked specifics in a decline.

an ambiguous single game, or the tool layer to allow a matchup summary under
clarification. Both are outside this worktree.
