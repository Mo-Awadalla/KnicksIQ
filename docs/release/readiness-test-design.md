# Readiness changes: failure cases specified before implementation

The stage tests enumerate missing/forged evidence, configuration-only proof,
wrong content/source identity, sample cherry-picking, unsampled calls, invalid
sampled answers, missing turns and bypassed owner authorization. Trace tests
cover request isolation and absent actual retrieval. HTTP regression must
exercise actual tool search and retain citations, replay and budgets.

Evaluation runner must refuse unfrozen contracts, unresolved semantic targets,
changed questions/expectations, missing owner label signatures, duplicate/missing
cases, fabricated traces, wrong runtime mappings, ambiguous outcomes, substring
scoring, uncapped paid access and production origins. A manual semantic review
protocol must bind spans and canonical facts to exact response hashes; no output
may become a new expected phrase. Counts and denominators are fixed first.

Browser checks must abort unmatched off-origin requests before network I/O,
reject production as a staging target, force fixture builds to /api, catch
redirects and service-worker bypass, and save per-test destination evidence.

Cancellation simulations must reach the mock provider before shortening its
response wait. Expiring source preparation or admission first creates no
transmitted-call receipt and cannot prove uncertain-cost reconciliation.
