# KnicksIQ landing reconstruction

User requested complete reconstruction, then explicitly requested Emil design engineering, shadcn plugin and Impeccable. User previously requested autonomous work ("yolo"). No external reference was supplied; this is an original reconstruction of the existing public archive.

## Product and scope

Preserve 2025–26 archive truth, existing logo/photo and policy links, React routing, readiness/error/retry behavior, question flow and persisted answers. Homepage only. Product context is recorded from repository evidence in PRODUCT.md; no new claims or metrics.

## Direction

A Knicks season program on warm paper: condensed display headlines, a panoramic Garden plate, a dark question desk, and editorial question rows. Display type is locally served Barlow Condensed 800. UI and color roles inherit the repo. The opening headline is deliberately larger than Impeccable's generic 6rem recommendation (8rem cap on wide screens) to carry the program-cover composition; tracking is -0.025em.

Concept material considered: sports back page, television recap, arena scoreboard, subway navigation, season program, ticket archive, photographic contact sheet. Season program supplies the complete page grammar. Foreign-form concepts from Impeccable were rejected where they obscured the archive task or implied unavailable browsing mechanics. The program retains material commitment and varied density without adding fictional game data.

## First viewport

Recognizable KnicksIQ masthead with full navigation; clear season context; two-line THE SEASON. STILL ALIVE. display; explanatory copy and functional Ask the archive anchor. A real Garden photograph follows. New content must remain visible without motion or network-dependent font services.

## Visitor path

Opening → ask the archive or browse game/report/source links → search panel → categorized starter questions or persisted answers → sources explanation → project disclosure and policies.

## Interaction

The primary CTA moves keyboard focus to the search section using a native anchor. shadcn Button and Field/Textarea carry the form, Alert carries errors. Existing submission behavior includes Enter, Shift+Enter and IME protection. Answer focus moves to the new response. Small press feedback comes from the canonical Button; no decorative entrances. Reduced motion removes movement. Navigation remains visible on phones.
